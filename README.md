# Car Dealership Inventory System

## Stack

- **Backend:** Node.js, TypeScript, Express, MongoDB, JWT
- **Frontend:** React, Vite, Tailwind CSS
- **Testing:** Vitest + Supertest (backend)

## Structure

```text
backend/
  src/
    config/
    controllers/
    middleware/
    models/
    routes/
    scripts/
    tests/
    utils/
    app.ts
    index.ts
frontend/
  src/
    components/
    pages/
    services/
    App.tsx
    main.tsx
    index.css
PROMPTS.md
```

## Setup

### Backend

```bash
cd backend
cp .env.example .env
npm install
npm run dev
```

### Frontend

```bash
cd frontend
cp .env.example .env
npm install
npm run dev
```
